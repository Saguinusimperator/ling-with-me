# Ling with me

小灵是可以待在 Windows 桌面上的动画伙伴。解压便携包后即可运行，不需要安装 Python、ChatGPT 或 Codex，也不需要联网才能使用独立桌宠。

![银色与红心白帽两套造型的真实播放预览](docs/assets/preview.gif)

## 下载与运行

正式下载入口将在发布验收完成后开放。仓库中的 `Ling-Windows.zip` 是当前候选包，尚未完成另一台干净 Windows 电脑上的试用。

1. 下载完整的 `Ling-Windows.zip`。
2. 完整解压 ZIP，保留其中整个 `Ling` 文件夹。
3. 双击 `Ling/Ling.exe`。

小灵会在桌面底边播放九种动作。鼠标悬停会触发跳跃，单击会挥手，拖动可以移动位置。右键点击小灵或系统托盘图标，可以换装、暂停、选择动作或退出。更多操作见[使用指南](docs/USER-GUIDE.md)。
