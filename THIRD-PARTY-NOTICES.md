### Qt/PySide6 source and replacement on macOS

The same unmodified upstream Qt/PySide6 6.12.0 source versions are available in [Ling-Qt-Source-v1.0.zip](https://github.com/Saguinusimperator/ling-with-me/releases/download/v1.0/Ling-Qt-Source-v1.0.zip), SHA-256 `cffaf59cca011827734b607679c228f538d6cf89ee9bf718810fcdb5db8a3436`. This is a source archive, not a Windows-only executable dependency; the old Release attachment is unchanged. Qt's module-specific bundled third-party texts are retained in `licenses/Qt-*`.

The app uses separate dynamic frameworks and Python extension modules under `Ling.app/Contents/Frameworks/PySide6/` and `Ling.app/Contents/Frameworks/shiboken6/` (plus the framework symlinks generated by PyInstaller). Users may replace these LGPL components with ABI-compatible modified builds and debug those changes; Ling's original-code license does not restrict those rights.

Close Ling and work on a backup copy of the app. Replace the relevant frameworks, dylibs or Python extension modules in place, retaining the relative paths, framework layout and symlinks. Replacements must match Apple Silicon, Qt/PySide6 6.12 and the packaged Python 3.13 ABI as applicable. Component replacement invalidates the original ad-hoc signature; re-sign the modified local copy with `codesign --force --deep --sign - /path/to/Ling.app`, then launch it. Restore the backup if it fails. This permits exercising LGPL rights; it does not grant additional rights to redistribute Ling's original code or artwork.

The notices are included both beside the app on the DMG and inside `Ling.app/Contents/Resources/Notices/`. PyInstaller itself is a build tool; its [license exception](https://pyinstaller.org/en/stable/license.html) covers generated application bundles.

## Qt/PySide6 source and replacement

The Qt/PySide6/Shiboken6 components are supplied as separate DLLs and Python extension modules in `Ling/_internal/PySide6/` and `Ling/_internal/shiboken6/`. Users may replace those LGPL components with ABI-compatible modified versions for debugging or use under the LGPL; Ling's custom code license does not restrict that right.

To substitute a compatible library in an extracted portable folder, close Ling, back up the target DLL or `.pyd`, copy the replacement to the same relative path and filename under `Ling/_internal/`, then start `Ling/Ling.exe`. The replacement must match the 64-bit Windows architecture and the Qt/PySide6 6.12 ABI; dependent libraries may need corresponding replacements. Restore the backed-up file if startup fails.

Corresponding source is provided as [Ling-Qt-Source-v1.0.zip](https://github.com/Saguinusimperator/ling-with-me/releases/download/v1.0/Ling-Qt-Source-v1.0.zip) with the v1.0 Release, SHA-256 `cffaf59cca011827734b607679c228f538d6cf89ee9bf718810fcdb5db8a3436`. It contains six official Qt/PySide6 6.12.0 source archives and a manifest of their URLs and hashes.

The Windows package targets Windows 10 x64 or later and uses the operating system's Universal C Runtime. Microsoft component use terms are in `MICROSOFT-TERMS.md`.
