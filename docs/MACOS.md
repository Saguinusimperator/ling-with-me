# Mac 独立桌宠（预览版）

## 下载与安装

下载 [Ling-macOS-arm64.dmg](https://github.com/Saguinusimperator/ling-with-me/releases/download/v1.2.0-macos-preview/Ling-macOS-arm64.dmg)，[发布说明与 SHA-256](https://github.com/Saguinusimperator/ling-with-me/releases/tag/v1.2.0-macos-preview)见预览版页面。本版 Retina 屏幕改用 2× 图集，清晰度明显提升。

- Apple Silicon（M 系列），不提供 Intel 版。
- 目标最低系统为 macOS 14；当前实际验证环境为 macOS 27.0，未在 macOS 14 上实测。
- 独立运行，不需要 Python、ChatGPT、Codex 或网络。

1. 打开 DMG，将 Ling 拖到“应用程序”。包内的说明和许可可按需阅读，应用内部也保留了一份。
2. 从“应用程序”启动 Ling。它没有 Dock 图标，右键点击小灵或菜单栏里的 Ling 图标可以打开菜单。
3. 退出时选择“退出 Ling”；更新时先退出，再用新版替换“应用程序”中的 Ling。换装设置会保留。

## 首次打开被拦截

预览版采用临时（ad-hoc）签名，未经 Apple Developer ID 签名和 Apple 公证。确认下载来源为本仓库后，先尝试打开一次，再到“系统设置 → 隐私与安全性”查找“仍要打开”，按系统提示确认。参考 [Apple 官方说明](https://support.apple.com/102445)。

不同系统版本或受管理的 Mac 可能显示不同提示，不保证所有拦截都能用此方式解除。如果提示文件损坏，先重新下载并核对发布页的 SHA-256，再反馈具体提示；不要关闭系统整体安全保护。

## 日常操作与设置

动画、两套造型、悬停跳跃、单击挥手、拖动、暂停和窗口停靠的操作见[使用指南](USER-GUIDE.md)。拖到普通窗口的上沿或下沿，看到提示后松手，即可趴住或悬挂；上沿需留出身体空间。

小灵跟随窗口移动、缩放；窗口关闭、最小化、隐藏、离开当前桌面，或者接触位置被挡住时回到底边。暂停时继续跟随窗口，但停止摆动。菜单中的“回到桌面底边”可找回小灵。

窗口读取使用 Quartz，只读取窗口几何和层级，不截屏、不依赖窗口标题、不主动请求录屏或辅助功能权限。读取失败时基础桌宠仍可使用。空白桌面没有可停靠窗口属于正常情况。

设置文件：`~/Library/Application Support/LingWithMe/settings.ini`。卸载时先从菜单退出，再将“应用程序”中的 Ling 移到废纸篓；如需同时清除设置，再删除上述 `LingWithMe` 文件夹。

## 已验证与已知限制

2026-11-05 在 macOS 27.0、Apple Silicon、单块 2× Retina 屏幕上，以临时真实 Qt 窗口验证了两套造型的上下沿吸附、移动/缩放跟随、暂停时跟随、隐藏、遮挡、最小化、关闭后解除和趴姿挥手。新版安装到“应用程序”并启动后，使用者已确认功能可用。

- Retina 屏幕使用 2× 图集（由原始生成条图重建），非 Retina 屏幕和 ChatGPT Pets 仍使用 1× 图集。
- 多屏及混合缩放、全屏应用和 Stage Manager 尚未完整验证。
- 只绑定当前桌面的可见普通窗口，不跨重启或跨桌面恢复。
- 预览版没有自动更新或开机自启。系统提供的窗口信息可能随 macOS 版本变化。

## 从源码构建

准备 uv 和 Python 3.13，在 Apple Silicon Mac 的仓库根目录执行 `bash build-macos.sh`。脚本创建或复用 `.venv`、安装固定依赖，并生成 `dist/Ling-macOS-arm64.dmg`。仅 Mac 安装 `pyobjc-framework-Quartz`，Windows 会自动跳过。

源码运行：安装 `requirements-build.txt` 后执行 `python ling_app.py`。更多构建和发布信息见[开发文档](DEVELOPMENT.md)。

## 白羽毛造型（1.3.0 起）

右键小灵 →「变装」→「白羽毛」。保留银色原版与红心白帽；白羽毛全部动作不含麦克风。素材同时提供 1× 与 2× 图集。1.3.1 起随下载链接一同发布。

### 白羽毛清晰度修复（1.3.1，build 5）

九组常规动作改为逐动作生成的高清素材，增加发丝、羽毛和服装轮廓的线条细节。
旧版主图每帧约 142×154，导出为 2× 时会放大原有模糊；新版打包要求原生单格至少
384×416，且拒绝放大角色像素，不使用锐化或超分补充细节。趴姿和悬挂素材保持原样。

更新时先退出正在运行的小灵，打开新 DMG，把其中的 `Ling.app` 拖到“应用程序”并选择
“替换”，然后从“应用程序”重新启动。直接把 `.dmg` 拖到“应用程序”只会移动镜像文件。
