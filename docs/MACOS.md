# Mac 独立桌宠

Mac 版支持桌面动画、拖动、换装、暂停和菜单栏图标，也支持窗口上沿停靠和下沿悬挂。操作与 Windows 版一致：拖动小灵，让身体碰到普通窗口的上沿或下沿，看到提示后松手。

停靠后小灵跟随窗口移动、缩放；窗口关闭、最小化、隐藏、离开当前桌面，或者接触位置被其他窗口挡住时，回到桌面底边。上沿需要留出身体空间；下沿允许身体伸出屏幕。暂停时仍跟随窗口，但停止摆动。可随时从菜单选择“回到桌面底边”。

窗口读取使用 Quartz，只读取窗口几何和层级，不截屏、不依赖窗口标题，也不自动请求辅助功能或录屏权限。缺少依赖或读取失败时，基础桌宠仍可使用，拖动时会显示原因。空白桌面没有可停靠窗口属于正常情况。

## 从源码运行与构建

安装 `requirements-build.txt` 后运行 `python ling_app.py`。Mac 专用依赖为 `pyobjc-framework-Quartz`，Windows 安装时会自动跳过。

Apple Silicon 上运行 `bash build-macos.sh` 生成 `dist/Ling-macOS-arm64.dmg`。打开后将 Ling 拖到 Applications。应用采用本机临时签名；若系统拦截，可在系统设置的“隐私与安全性”中允许打开。

## 使用边界

2026-11-05 在 macOS 27.0、Apple Silicon、单块 2× Retina 屏幕上，通过临时真实 Qt 窗口验证了两套造型的上下沿吸附、移动/缩放跟随、暂停时跟随、隐藏后解除，以及遮挡、最小化、关闭后解除和趴姿挥手。验证由脚本驱动真实窗口，尚未进行人工鼠标拖放体验确认。

只绑定当前桌面的可见普通窗口，不跨重启或跨桌面恢复。全屏应用、Stage Manager、混合缩放多屏，以及菜单和系统浮层的表现仍需实际使用确认。窗口信息由系统提供，不同 macOS 版本可能有差异；若普通窗口始终无法识别，请先反馈系统版本和拖动时的提示，不必预先开启录屏权限。
